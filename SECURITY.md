# Security Policy

## Supported Versions

Security fixes are handled on `main` until the project publishes stable release branches.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting: open the Security tab of https://github.com/goldenlobster2019-bit/logic-groove-mcp and choose "Report a vulnerability". Do not open a public issue for an unpatched vulnerability.

For issues involving local macOS permissions, include the macOS, Logic Pro, and LogicGrooveMCP versions and identify whether Accessibility, Automation, MIDI, or OSC permissions are involved.

Do not include Logic project files, credentials, private keys, or other secrets.
